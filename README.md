# PowerBI_Dashboard-Project
# Payment Analytics Dashboard | Power BI

## 📊 Project Overview

An interactive Power BI dashboard developed for a fictional PhonePe payments case study. The dashboard provides an overview of payment performance by analyzing transaction volume, transaction value, user activity, service categories, customer age segments, and weekday vs. weekend usage.

The objective was to transform transactional data into an interactive business intelligence dashboard that enables stakeholders to identify trends and understand customer and service-level payment behaviour.

> **Note:** This is a fictional case study created for portfolio and learning purposes. It is not based on real PhonePe business data.

---

## 🎯 Business Objectives

The dashboard was designed to answer key business questions such as:

- How are transaction volume and transaction value changing over time?
- Which services contribute the most to transaction value?
- Which age group contributes the highest transaction volume?
- How does payment activity differ between weekdays and weekends?
- What is the overall payment success rate?
- Who are the highest-value users based on transaction value?

## 🔍 Key Insights

- **Loans** generated the highest transaction value at approximately **₹2.5Bn**, making them the strongest-performing service category.
- **Millennials** accounted for **37.4% of total transaction volume**, representing the largest age segment.
- **Weekday transactions** accounted for **71.6%** of total activity compared with **28.4%** on weekends, making weekday transaction volume approximately **2.5× higher**.
- The dashboard provides a monthly view of **transaction value and transaction volume**, allowing changes in payment activity to be monitored over time.
- Service-level analysis highlights differences in transaction value across categories such as Loans, Insurance, Money Transfer, and Recharge.
